# Where Rigline works

Rigline works in VS Code on Windows, macOS and Linux, in a local window, with Node 22.12 or newer.
Where it does not work yet, it leaves Claude Code's panel as it ships, and the companion extension
says *Rigline: not in this editor*.

## Editors and windows

|                  | In a local window | In a remote window |
| ---------------- | ----------------- | ------------------ |
| VS Code          | Supported         | Not yet            |
| VS Code Insiders | Not yet           | Not yet            |
| Cursor           | Not yet           | Not yet            |
| Windsurf         | Not yet           | Not yet            |
| VSCodium         | Not yet           | Not yet            |

A remote window is one whose workspace lives somewhere else: WSL, Remote - SSH, Dev Containers or
GitHub Codespaces.

## How VS Code is installed

| Install                                              | Status    |
| ---------------------------------------------------- | --------- |
| The usual install, in any of its profiles            | Supported |
| A portable VS Code                                   | Not yet   |
| A custom extensions directory (`--extensions-dir`)   | Not yet   |

## Asking for one

Nothing marked *not yet* has a date. What comes first depends on how many people want it, not on who
asked first, so if you want one, say so: open an issue at
[github.com/Rigline/Rigline](https://github.com/Rigline/Rigline/issues), or give a thumbs-up to one
that is already there. The thumbs-ups are how we count.
